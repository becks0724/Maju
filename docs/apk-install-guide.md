# Maju(마주) 심사위원용 APK 설치 안내

**한 줄 요약.** 갤럭시 휴대폰에 휴대폰 APK 하나를 설치하면 처음 설정과 「휴대폰 단독 테스트」를 직접 해 보실 수 있도록 만들었습니다(제출 빌드를 기기에서 끝까지 돌린 기록은 아직 없습니다 · [기기 확인 날짜 — PM]). 실제 119 로는 보내지 않습니다.

| APK | 혼자 설치했을 때 |
|---|---|
| 휴대폰 [자리표시 — 파일 이름] | **동작하도록 만들었습니다**(제출 빌드를 기기에서 끝까지 돌린 기록은 아직 없습니다 · [기기 확인 날짜 — PM]). 처음 설정 · 동의 · 보호자 등록 · 휴대폰 단독 테스트 |
| 워치 [자리표시 — 파일 이름] | 설치는 되지만 혼자서는 감시를 시작하지 못합니다(아래 4절) |
| 차 [자리표시 — 파일 이름] | 설치는 되지만 혼자서는 휴대폰 · 워치와 이어지지 않습니다(아래 4절) |

세 APK 는 같은 키로 서명한 release 판입니다.

## 1. 설치 — 휴대폰

- **필요한 기기.** Android 11 이상의 갤럭시 휴대폰. 시험은 갤럭시 노트10(Android 12)에서 했습니다.
- **설치.** APK 파일을 휴대폰에 옮겨 엽니다. 「출처를 알 수 없는 앱 설치」 허용을 묻으면 허용합니다. PC 에서는 `adb install <휴대폰 APK 파일>` 로도 설치할 수 있습니다.
- 앱 이름은 **Maju** 로 보입니다.

## 2. 처음 설정

화면 순서대로 진행합니다. 값은 시험용으로 넣으셔도 됩니다.

1. 「시작하기」 → 대상 범위와 한계 안내를 읽습니다.
2. **운전자 · 차량** — 이름 · 생년월일 · 차 색 · 번호판(시험용 값 가능).
3. **보호자** — 이름과 010 으로 시작하는 휴대폰 번호. **본인이 받을 수 있는 번호를 넣어 주십시오**(5절 주의).
4. **동의 세 가지** — 모두 동의해야 기능을 켤 수 있습니다. 동의 문구는 판 3(2026-11-13)입니다. 앞 판에 동의해 둔 휴대폰은 앱을 열면 동의 화면이 다시 나오고, 다시 동의해야 합니다.
5. **권한** — 위치 · 문자 · 알림(Android 14 이상은 잠금 화면 전체 화면 알림도)을 허용합니다. 이 넷은 기능을 켜는 데 필요합니다.
   - 「방해 금지 중 알람」은 선택입니다. 허용하면 방해 금지 중에도 알람이 울립니다.
   - 「위치 항상 허용」도 선택입니다. 허용하지 않아도 기능을 켤 수 있습니다. 휴대폰을 다시 켜거나 앱이 업데이트된 뒤에도 앱을 열지 않고 위치를 받으려면 필요합니다. 위치는 기능이 켜져 있는 동안에만 받습니다.
6. **차와 연결** — 「중계 서버 주소가 없는 빌드입니다 · 휴대폰 혼자 동작합니다」가 보이면 정상입니다. 「다음」을 누릅니다.
7. **홈** — 「준비가 끝났습니다 · 오른쪽 스위치로 켜세요」에서 스위치를 켭니다. 기능은 기본 꺼짐입니다.

## 3. 테스트 모드로 보는 법

1. 홈에서 「테스트 모드」를 엽니다.
2. 실행 기기는 「휴대폰만」을 고릅니다.
3. 실내에서는 정차 여부를 알 수 없어 「정차 중입니다」를 먼저 누릅니다.
4. 「테스트 시작」을 누르면 다음 순서로 진행됩니다. 화면에는 늘 「테스트 · 실제 상황 아님」이 표시됩니다.
   - 경보 1 · 진동 15초
   - 경보 2 · 소리 20초(무음 · 진동 모드에서도 알람 음량으로 울립니다)
   - 응답 없음 · 「보호자에게 테스트 문자를 보낼까요?」 — 「보내기」 또는 「보내지 않기」
   - 119 미리보기 — 「미리보기 · 119 로 보내지 않습니다」. 보내기 경로가 없습니다.
5. **응답한 경우를 보시려면** 경보 중에 「괜찮아요」를 누릅니다. 응답 뒤 화면과 「몸 상태가 걱정되면 의료진과 상담해 보세요」 안내가 나옵니다.
6. 끝내려면 「테스트 멈추기」를 누릅니다.

**문자는 이렇게 됩니다.**
- 「보내지 않기」를 고르면 아무 문자도 나가지 않습니다.
- 「보내기」를 고르면 SIM 이 있는 휴대폰은 보호자 번호로 첫 줄에 `[테스트]` 가 붙은 문자를 **실제로 보냅니다.** 통신사 요금이 들 수 있습니다.
- SIM 이 없으면 「보내지 못함」으로 끝납니다. 팀의 시험 휴대폰도 SIM 이 없어 여기까지 확인했습니다(11-14 판으로는 아직 돌리지 않았습니다).
- 테스트 문자는 다시 보내지 않습니다. 경보 화면의 「보호자 문자 다시 보내기」는 실제 사건의 문자를 보내지 못했을 때 정차 중에만 나오므로, 휴대폰 단독 테스트에서는 보이지 않습니다.

## 4. 워치 · 차 APK 가 혼자서 동작하지 않는 이유

- 워치와 차는 **중계 서버를 거쳐** 휴대폰과 짝을 지어야 이어집니다. 차 앱은 문자를 보낼 수 없고 워치와 직접 이어지지 않기 때문입니다.
- 공개 중계 서버는 두지 않았습니다. 위치 · 건강 관련 정보를 다루는 서버라, 암호화 통신 · 연결 번호 대입 막기 · 위치정보법 검토를 갖추기 전에는 열지 않기로 했습니다.
- 그래서 워치 release APK 는 혼자서 심박 감시를 시작하지 못하고, 차 release APK 는 휴대폰 · 워치와 이어지지 않습니다. 각 APK 를 혼자 켰을 때 보이는 화면은 아직 기기로 기록하지 못했습니다[미검증].
- 홈 「보낸 문자 기록」의 「문자 상한」 표시는 차에서 온 문자 요청이 상한(10분 3통 · 24시간 10통, 에어백 전개 문자는 같은 값을 따로 셉니다)에 걸렸을 때만 붙습니다. 휴대폰 단독으로는 보이지 않습니다.
- 차 APK 는 Pleos 차량용 앱이라 일반 휴대폰이 아니라 Pleos 에뮬레이터 또는 Pleos 탑재 차량 환경에 설치합니다. 팀은 Pleos 에뮬레이터에서만 시험했습니다.

**세 기기가 이어지는 모습은 시연 영상([자리표시 — 영상 링크])에서 보실 수 있습니다.** 영상은 같은 코드의 debug 판을 시험용 LAN 중계에 붙여 찍었고, 주행 상태는 시험 컨트롤러로 만든 것입니다. 2차 PT 에서는 동작하는 앱으로 시연합니다.

## 5. 주의

- 이 앱은 의료기기가 아닙니다. 모든 상황을 알아차리지는 못합니다. 위급하면 직접 119 에 연락하세요.
- 보호자 번호에는 본인이 받을 수 있는 번호를 넣어 주십시오. 「보내기」를 누르면 테스트 문자가 실제로 나갈 수 있습니다.
- 앱은 119 로 문자나 전화를 보내지 않습니다.
- 시험을 마치면 홈(정차 중)의 「동의 철회 · 기록 지우기」로 등록 정보 · 동의 · 문자 기록을 지운 뒤 앱을 삭제하시면 됩니다.
